# 本地 daemon HTTP 面

Personal daemon 在 loopback 监听器上提供的路由（外加 daemon 创建的一次性私有 socket，用于 Pi candidate completion）。通道：`none`（免认证）、`management` 与 `task`（经 `POST /local/session` 铸造的通道绑定本地 bearer）、`private-socket`（Unix socketpair，绝不走 TCP）。未知的 `/task/*` 路径当前返回 HTTP 200 加 "no Task API operation matched" 注记而非 404（已记录的实现缺口）。
