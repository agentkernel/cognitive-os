# Configuration and state files

Non-secret configuration and state files owned by the Personal daemon and CLI under the XDG layout. Provider/user secret material never enters any of these files; it lives only in the approved SecretStore backend.

| File | Location | Purpose |
|---|---|---|
| `provider.json` | `XDG config / cognitiveos` | Non-secret Provider configuration: provider id, HTTPS base URL, opaque SecretRef, optional snapshot digest. |
| `selected-model.json` | `XDG config / cognitiveos` | Selected chat-capable model plus the discovery snapshot digest it was chosen from. |
| `pi.json` | `XDG config / cognitiveos` | Non-secret Pi launch configuration: absolute executable and Extension entry paths. |
| `daemon-endpoint.json` | `XDG state / cognitiveos` | Atomically published loopback endpoint document consumed by CLI and Pi extension. |
| `local-bootstrap.secret` | `XDG runtime / cognitiveos` | Per-boot bootstrap proof (0600) exchanged at POST /local/session for channel-bound bearers. Never leaves the local machine. |
| `migration.lock` | `XDG runtime / cognitiveos` | Exclusive lock taken while preparing/migrating the two SQLite databases. |
| `daemon.lock` | `XDG runtime / cognitiveos` | Single-daemon-instance lock; `cognitive daemon stop` removes it only after confirming staleness. |
| `active-version` | `deployment root` | Atomic text pointer naming the active installed bundle version; switched only after health confirmation. |
