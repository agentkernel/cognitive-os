## Executive summary

Owner claim **「距离原型图和产品设计差距很大，根本不能用」** is **substantiated for the 小白 Owner job** (create a governed live Project, supervise Members, open deliverables, approve consequential work, and live in Today). It is **not** a claim that the daemon or Dual Track L1 hashes are absent.

What works: management-session gate; L1 Today / Projects / Knowledge; honest empty / creating / fail-closed copy; five-step wizard that can mint a digest-bound draft + `creating` Project; four Project submenus; SecretStore handoff form that stays disabled until a key is typed; Inbox / Team / `#/hitl` correctly 404; dsh is a separate native panel.

What fails the product job: create wizard is five **note textareas**, not ①–⑤ process/member/test/joint; Write Project leaves `creating` with **title `unknown`** and **no PlanRevision axis**; member join **fail-closes** (no slots); Today never becomes the v9 decision-packet + live-run overview; Settings dumps a 9×9 state-lab into the default page; Settings is not a real L1 control in the accessibility tree; Linux 1.0 Home / Work / Agents / Providers remain reachable and the command palette advertises them; Assistant is Provider-unbound so conversation cannot drive setup; Knowledge is an HTTP paste/admin form, not v9 files / Why this fragment / import chrome.

**Verdict (hypothesis):** Dual Track `/ui/` is a walking-skeleton Control Plane with honest refusals. It is **not** the frozen v9 Owner console. A first-run Owner cannot reach ⑤ 验收 or a live Today.
