# Personal reflection and learning loop

- Status: current candidate/admission foundation plus OPC target
- Related: AXIOMS P3,
  [Conversation/Memory/Vault](conversation-memory-vault.md), and
  [Authority/recovery](authority-data-and-recovery.md)

## 1. Current foundation

Verified success/failure can produce digest-bound Memory and Skill candidates.
Memory uses daemon admission; Skill uses immutable import/bind/revoke.
Provenance and failure context remain attached. Direct promotion,
self-authorization, and forgotten/revoked resurrection fail closed.

## 2. OPC candidate sources

Eligible sources include:

- Personal Conversation archive fragments;
- Project Vault/source facts;
- Task/Attempt/Effect/evidence outcomes;
- key-result and daily/weekly reflection;
- manager/employee/DSH/Pi candidates;
- connector metric readback;
- MCP advertisements/results in the advanced track;
- Owner correction and explicit feedback.

Broader inputs do not broaden authority. Every source retains Project/employee/
Task scope, provenance, freshness, coverage, and untrusted status.

## 3. Admission

```text
source observation
  -> correlation with current authority/evidence
  -> reflection/Memory/Skill/plan candidate
  -> deterministic policy + conflict review
  -> admitted object or rejected/retained candidate
```

Only verified facts or explicit Owner intent may become semantic Memory.
Reflection can propose a Plan/Routine/role change but cannot apply it. Manager
agreement, self-critique, repeated text, reward, process exit, Provider success,
or DSH checkpoint is not verification.

## 4. Plan and responsibility evolution

Within-boundary manager adjustments still use current daemon policy and
versions. Primary goal, team, budget, Provider, Tool, permission, or external
rule changes become structured revision candidates and require Owner
confirmation. Past revisions and Attempts remain.

## 5. Privacy, conflict, and forget

Secret-bearing candidates are refused before persistence; redaction afterward
is insufficient. Retained content needs purpose, scope, provenance, retention,
and inspect/correct/forget behavior. Conflicts remain visible and cannot use
last-write-wins or model judgment alone.

Letta and Mem0 remain candidate extraction/retrieval references; they do not
write Personal Memory, run default telemetry, consume env secrets, or own a
second authority store.

## 6. Evaluation and non-claims

Learning quality needs later independent outcomes, correction, conflict,
reuse, and forgetting evidence. Candidate/admission counts do not prove
benefit. OPC reflection/archive integration remains **Requires-backend**. No
Gate, release, Profile, memory-quality, business-outcome, or Agent-benefit
claim follows.
