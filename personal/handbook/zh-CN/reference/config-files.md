# 配置与状态文件

Personal daemon 与 CLI 在 XDG 布局下拥有的非 secret 配置/状态文件。Provider/用户 secret 材料绝不进入其中任何文件，只存放在批准的 SecretStore 后端。

| 文件 | 位置 | 用途 |
|---|---|---|
| `provider.json` | `XDG config / cognitiveos` | 非 secret 的 Provider 配置：provider id、HTTPS base URL、不透明 SecretRef、可选 snapshot digest。 |
| `selected-model.json` | `XDG config / cognitiveos` | 选定的可对话模型及其来源发现快照的 digest。 |
| `pi.json` | `XDG config / cognitiveos` | 非 secret 的 Pi 启动配置：可执行文件与 Extension 入口的绝对路径。 |
| `daemon-endpoint.json` | `XDG state / cognitiveos` | 原子发布的 loopback endpoint 文档，供 CLI 与 Pi 扩展消费。 |
| `local-bootstrap.secret` | `XDG runtime / cognitiveos` | 每次启动的 bootstrap 证明（0600），在 POST /local/session 兑换通道绑定 bearer。绝不离开本机。 |
| `migration.lock` | `XDG runtime / cognitiveos` | 准备/迁移两个 SQLite 数据库期间持有的排他锁。 |
| `daemon.lock` | `XDG runtime / cognitiveos` | daemon 单实例锁；`cognitive daemon stop` 仅在确认过期后移除。 |
| `active-version` | `deployment root` | 指向当前激活 bundle 版本的原子文本指针；仅在健康确认后切换。 |
