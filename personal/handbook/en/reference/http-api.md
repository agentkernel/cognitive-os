# Local daemon HTTP surface

Routes served by the Personal daemon on its loopback listener (plus the daemon-created one-shot private socket used for the Pi candidate completion). Channels: `none` (unauthenticated), `management` and `task` (channel-bound local bearers minted via `POST /local/session`), `private-socket` (Unix socketpair, never TCP). Unknown `/task/*` paths currently return HTTP 200 with a "no Task API operation matched" note rather than 404 (a recorded implementation gap).
