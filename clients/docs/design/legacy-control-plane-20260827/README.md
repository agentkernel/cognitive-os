This directory archives the complete previous `clients/docs/design` corpus:
numbered documents `01` through `41`, the current-state map, capability
inventory, and design-skill manifest. It remains useful as dated as-built
evidence, design rationale, and P7-T05 planning history, but it does not define
the current Personal 2.0 product, IA, component map, implementation order, or
readiness.

In particular, `26`–`34`, `control-plane-current-state.md`, and
`control-plane-capability-inventory.md` retain their original factual
current-state/API/capability audit. Their facts are not edited to match the OPC
target. Documents `09`, `11`, `22`, and `24` retain useful Apple-inspired
clarity, token, state, accessibility, and visual principles; the current OPC
corpus restates only the principles still adopted.

## Supersession

The old active semantics centered Home/Agents/Work/Library/Activity/Settings,
external/native Agent conversations, and P10 implementation waves. The current
successor centers Today/Projects/Team/Knowledge/Inbox, a Project briefing,
Personal-owned employee conversations, a global Personal Assistant,
preinstalled managed DSH, Windows-local long-running work, and explicit
Requires-backend matrices.

Internal relative links continue to resolve because the corpus moved as one
unit. External references should link either to this frozen directory for a
dated fact or to the current OPC index for target behavior. Nothing here
creates a current implementation, support, Gate, release, Profile, usability,
or Agent-benefit claim.
